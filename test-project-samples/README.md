# Code Count - Sample Projects

This directory contains various sample projects designed to test and demonstrate the capabilities of the **Code Count** VS Code extension.

---

## 📁 Sample Overview

| Directory | Purpose | Key Features |
| :--- | :--- | :--- |
| `basic-example` | Basic Verification | Simple TS/JS, `.gitignore` check |
| `javascript-react` | Modern Frontend | React (JSX), Modern ESM |
| `python-flask` | Multi-language Support | Python, `#` comments, docstrings |
| `rust-cargo` | Systems Programming | Rust, complex nested comments |
| `deep-bench` | Stress Test | **51-level** deep recursion |
| `edge-cases` | Edge Cases | Unicode paths, Emojis (🚀), Minified files |

---

## 📊 Expected Results

Check the `test-results/` directory for verified reference outputs.

Users can scan these samples to verify that their extension is working correctly and to understand how different line types (Code, Comment, Blank) are detected across various languages.
